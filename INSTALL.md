# Установка ST67 Сметчик 0.2.0

Поддерживаются macOS и Linux с установленными Codex CLI и Python 3.11+.

## Плагин из публичного GitHub

```bash
codex plugin marketplace add RomanovVIII/st67-smetchik --ref v0.2.0
codex plugin add st67-smetchik@st67-smetchik
```

После установки открой **новую задачу Codex**: новая задача обнаружит skill и его инструкции.
Проверить источники можно командой `codex plugin list`. Удаление плагина:

```bash
codex plugin remove st67-smetchik
```

Универсальный каталог OpenAI в выпуск `0.2.0` не входит. Команда выше закреплена за неизменяемым
релизным тегом `v0.2.0`. Установка без `--ref` считается каналом разработки и может получить
более новый код из ветки `main`.

## Локальный runtime

Из корня установленного плагина сначала установи runtime, затем проверь его без сети:

```bash
python3 runtime/bootstrap.py
python3 runtime/bootstrap.py --verify-only
```

Runtime работает в пользовательском каталоге `$HOME/.local/share/smetchik/venv`; это
установленное виртуальное окружение, а не исходный каталог `runtime/`. `--verify-only` не
загружает зависимости. Обычный bootstrap может обратиться к настроенному индексу пакетов.

## Официальные XSD

Сторонние XSD не поставляются с плагином. Получи их только из адресов и с хэшами, указанными в
`schemas/registry.json`:

```bash
python3 runtime/schema_manager.py fetch --all
python3 runtime/schema_manager.py verify
```

По умолчанию схемы хранятся в `$HOME/.local/share/smetchik/schemas`. Для изолированного набора
задай `SMETCHIK_DATA_DIR` перед обеими командами. Менеджер использует HTTPS, проверяет SHA-256
архивов и XSD и устанавливает данные атомарно. Для одного RAR нужен установленный `unar`; если
его нет, команда точно укажет ограничение и не пометит полный набор схем как установленный.

Проверка пользовательского XML/GGE никогда не скачивает XSD и не доверяет `schemaLocation`.
Если нужной схемы нет локально, результат получает статус `schema_not_installed` и не выдаёт
семантическую или стоимостную проверку за выполненную.

# XML и формат GGE

XML обрабатывается только локально и без сетевого разрешения схем/сущностей.

## Безопасный разбор

- Запрети DTD, внешние сущности, XInclude и сетевую загрузку `schemaLocation`.
- Применяй лимиты размера, глубины, количества узлов и распакованного объёма.
- Используй только локально поставляемую и идентифицированную схему. Сохраняй имя/версию схемы и результат валидации.
- Не исполняй вложенный код, преобразования или ссылки.

## Известная схема

Смысловые поля и арифметика допустимы только если формат однозначно распознан по локальной схеме/профилю и требуемые поля надёжно сопоставлены. Для каждого значения сохраняй XPath, namespace и при наличии номер строки.

Файл `.gge` не считается автоматически известным только по расширению. Зафиксируй фактический контейнер, версию формата и локальную схему. Чек-лист ГГЭ — отдельный методический профиль, а не XSD и не нормативный акт.

Полностью поддерживаемый маршрут v1 ограничен локальными версионированными XSD Минстроя и опубликованными XSD ГРАНД-Сметы из `schemas/registry.json`. MGE используется только как региональный московский adapter с `partial_extraction`, пока опубликованные архивы XSD недоступны. Smeta.RU, EstML и другие проприетарные схемы без проверенной спецификации получают `partial_extraction` или `unsupported_schema`.

## Неизвестная или неподдержанная схема

Разрешён только структурный инвентарь:

- SHA-256, размер, кодировка и XML-декларация;
- корневой элемент, namespaces и заявленные schema locations как текстовые данные;
- количество элементов/атрибутов, дерево верхнего уровня и повторяющиеся имена;
- ошибки well-formedness и безопасного парсинга.

Запрещено угадывать по именам тегов суммы, количества, расценки, НДС или связи смет. Не выполняй смысловую арифметическую, нормативную или позиционную проверку. Зафиксируй `limited`/`unsupported`, `row_level_checked = false` для этого входа и точное требование к схеме или экспорту.

## GGE и внешние системы

Не загружай файл в ГГЭ, КСПР/КПСР, ФГИС ЦС или иной портал. Не утверждай, что локальная структурная/схемная проверка равна успешной приёмке информационной системой или экспертизе.

XML/GGE не исправляй. По прямой команде создай отдельный sidecar-отчёт; оригинал и его SHA-256 должны остаться неизменными.

# Runtime

ST67 Сметчик использует отдельное окружение по умолчанию:
~/.local/share/smetchik/venv.

Создание и установка точных зависимостей выполняются только явной
командой:

    python3 runtime/bootstrap.py

Проверка без изменений и без сетевой установки:

    python3 runtime/bootstrap.py --verify-only

Скрипт не запускает сервисы, не открывает порты и не читает
пользовательские документы. Для PDF дополнительно требуются локальные
Poppler (pdftotext, pdftoppm) и Tesseract с языками rus и eng.

requirements.in фиксирует прямые зависимости. requirements.lock
фиксирует прямые и транзитивные версии и SHA-256 допустимых дистрибутивов
снимка 26.08.2026; bootstrap требует хэши и бинарные wheels. Отдельный
requirements-ci.lock добавляет только инструменты проверки CI. При этом
исходный каталог `runtime/` с bootstrap и lock-файлом является частью
исходников и входит в Git и переносимый release-архив. В Git, архив
переноса и резервную копию не входит только установленное виртуальное окружение
`$HOME/.local/share/smetchik/venv`; на другой машине его
пересоздают из lock-файла.

# Политика безопасности

## Границы данных

`st67-smetchik` обрабатывает документы локально. Не добавляйте в issue, лог или репозиторий
реальные сметы, персональные данные, токены, пароли, ключи и коммерческие предложения.

Во время анализа пользовательских XML/GGE плагин не обращается к сети и не использует
`xsi:schemaLocation`. Внешняя сеть нужна только для явно запущенного
`runtime/schema_manager.py fetch --all`; менеджер принимает исключительно HTTPS-адреса из
`schemas/registry.json` и проверяет SHA-256 до установки.

## Сообщить об уязвимости

Не публикуйте детали уязвимости в открытом issue до устранения. На странице репозитория
`RomanovVIII/st67-smetchik` откройте **Security → Report a vulnerability** и создайте приватный
security advisory с версией, затронутым путём, шагами воспроизведения и оценкой влияния. Не
включайте чувствительные документы: замените их минимальной синтетической фикстурой.

Мы подтвердим получение, оценим воспроизводимость и согласуем безопасное раскрытие. Публичные
исправления публикуются через GitHub Release. Критические и важные проблемы исправляются до
следующего выпуска.

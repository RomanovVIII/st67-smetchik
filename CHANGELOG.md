# Журнал изменений

Все заметные изменения этого проекта документируются в этом файле.

## [0.2.0] — 2026-08-26

### Added

- Публичный Codex plugin marketplace для `RomanovVIII/st67-smetchik`.
- Лицензия MIT, инструкции установки для macOS и Linux, политика безопасности.
- Реестр официальных XSD-источников и документированный локальный менеджер схем.
- CI для Ubuntu/macOS и Python 3.11–3.13, CodeQL и gitleaks.

### Changed

- Публичная установка использует `codex plugin marketplace add` и `codex plugin add`.
- XSD больше не входят в пакет: проверяемая локальная установка выполняется отдельно.
- Python-зависимости закреплены версиями и SHA-256; установка требует binary wheels.
- Установка marketplace закреплена за неизменяемым тегом `v0.2.0`.
- Загрузка и распаковка схем ограничены по размеру, числу файлов, степени сжатия и времени.

### Removed

- Сторонние XSD исключены из дерева поставки; вместо них публикуется реестр официальных источников и контрольных SHA-256.

## [0.1.0]

- Внутренний исходный выпуск ST67 Сметчик.

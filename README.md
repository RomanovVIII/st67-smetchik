# ST67 Сметчик

`st67-smetchik` v0.2.0 — независимый Codex-плагин Studio 67 под лицензией MIT для локальной доказательной проверки сметной документации России. Имя skill и явный вызов остаются `smetchik` и `$smetchik`.

Плагин работает с Excel, PDF/сканами и XML/GGE; DOCX и ZIP используются как вспомогательные форматы. Сторонние XSD не входят в дистрибутив: их официальный реестр, хэши и правила выбора находятся в `schemas/registry.json`, а локальная установка выполняется отдельной командой. Локальная проверка документов через CLI `inspect` и запуск `runtime/bootstrap.py --verify-only` не требуют сети и не загружают документы во внешние сервисы; использование самого Codex подчиняется режиму данных той установки, где запущен плагин. Обычный запуск `runtime/bootstrap.py` устанавливает зависимости через `pip` и поэтому может обращаться к настроенному индексу пакетов. Исходники по умолчанию не изменяются.

Перед проверкой фиксируется паспорт: цель, объект, вид работ, источник финансирования, регион/ценовая зона, дата уровня цен, метод расчёта, стадия и состав документов. Цели охватывают внутреннюю проверку, подготовку/повторную экспертизу, разбор замечаний, проектную и договорную смету с изменениями. Виды работ охватывают строительство, реконструкцию, ремонт/капремонт, снос, ОКН, ПИР и изыскания.

## Режимы

| Режим | Назначение | Что не заявляется |
|---|---|---|
| `light` | Быстрый обзор всего комплекта на макроуровне: комплектность, иерархия, итоги, уровень цен и основные риски | Нет процентной выборки и нет утверждения о проверке каждой строки |
| `full` | Максимально сплошная проверка каждой надёжно извлечённой позиции, формулы и связи | Нечитаемые и неподдержанные области перечисляются, а не считаются проверенными |

Режим обязателен и никогда не выбирается автоматически.

## Использование в Codex

Явный вызов:

```text
Используй $smetchik в режиме light: проверь весь приложенный комплект и покажи основные риски.
```

```text
Используй $smetchik в режиме full: проверь ЛСР, ОСР, ССР, ведомость объёмов и КАЦ; результат дай в чате.
```

Skill допускает неявное обнаружение по запросам о сметах, но без указанного `light`/`full` сначала задаст один сгруппированный вопрос.

## Локальный CLI

После отдельной установки runtime из корня плагина:

```bash
"$HOME/.local/share/smetchik/venv/bin/python" \
  skills/smetchik/scripts/smetchik_cli.py inspect /path/to/package \
  --mode full --purpose "внутренняя проверка" \
  --object-name "объект" --work-type "capital_repair" \
  --funding-source "budget" --region-or-price-zone "67" \
  --price-level-date "2026-08-01" --calculation-method "resource_index" \
  --stage "project_documentation" --document-set "LSR"
```

По умолчанию компактный JSON выводится в stdout. `--output-json` создаёт только новый файл и отказывается перезаписывать существующий. CLI выполняет безопасное извлечение и детерминированные контроли; итоговую нормативную применимость и визуальную сверку сканов выполняет skill.

### Безопасное исправление по прямой команде

Исправление запускается только после отдельной прямой команды пользователя. Запрос должен соответствовать [smetchik.corrections.v1.schema.json](skills/smetchik/assets/smetchik.corrections.v1.schema.json), содержать точный `source_sha256` и для каждой правки — `id`, `status`, `target`, `expected_old`, `replacement`, `reason`:

```bash
SMETCHIK_PLUGIN_ROOT="/path/to/st67-smetchik"
SMETCHIK_PYTHON="/path/to/smetchik-runtime/bin/python"
"$SMETCHIK_PYTHON" \
  "$SMETCHIK_PLUGIN_ROOT/skills/smetchik/scripts/smetchik_cli.py" correct source.xlsx \
  --corrections-json corrections.json \
  --output corrected.xlsx \
  --changelog changelog.json
```

Подставь пути текущей установки: пример одинаково применим в Linux и macOS и не зависит от домашнего каталога пользователя. `correct` сверяет SHA-256 и старое значение, создаёт `output` и `changelog` в режиме create-only и не перезаписывает оригинал. Для XLSX/XLSM правка со статусом `confirmed` применяется к новой копии, а `disputed` только аннотируется. Для XLS/PDF/XML/GGE/MGE создаётся JSON-sidecar без изменения источника. Формулы как новое значение и строки, похожие на активную формулу или внешнюю ссылку, в v1 отклоняются.

## Установка из публичного repository marketplace

Поддерживаются macOS и Linux. Публичная установка, подготовка runtime и локальных схем описаны в [INSTALL.md](INSTALL.md):

```bash
codex plugin marketplace add RomanovVIII/st67-smetchik --ref v0.2.0
codex plugin add st67-smetchik@st67-smetchik
```

После установки открой новую задачу Codex, чтобы она обнаружила skill. Удаление: `codex plugin remove st67-smetchik`. Плагин не требует MCP, connector, hook, аккаунта или сетевого сервиса. Публикация в универсальном каталоге OpenAI в выпуск `0.2.0` не входит.

## Контракт результата

Машиночитаемый результат имеет версию `smetchik.result.v1` и валидируется схемой:

`skills/smetchik/assets/smetchik.result.v1.schema.json`

Запрос на исправление имеет отдельный контракт `smetchik.corrections.v1`:

`skills/smetchik/assets/smetchik.corrections.v1.schema.json`

Finding всегда отделён от вопроса и ограничения и содержит severity, confidence, точный локатор, расчёт/основание и действие. Нормативные выводы требуют проверки актуальности официального источника на дату запуска.

## Границы

Сметчик не заменяет проектную или государственную экспертизу и не делает выводы о НМЦК, закупочной процедуре, КС-2/КС-3, инженерной безопасности или подлинности документов. Смета контракта проверяется только в явно заданном сметно-арифметическом объёме.

Сохранение отчёта или исправление разрешены только прямой командой. Excel исправляется в новой копии с журналом; для PDF/XML создаётся sidecar; оригинал не перезаписывается.

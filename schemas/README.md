# Реестр локально устанавливаемых XML-схем

В дистрибутиве нет XSD. `registry.json` хранит только официальные URL, ожидаемые SHA-256
архивов и XSD, внутренний `archive_path`, локальный `path` и правила выбора адаптера. Загрузка выполняется только явной командой
`python3 runtime/schema_manager.py fetch --all` и устанавливается в
`~/.local/share/smetchik/schemas` (или каталог из `SMETCHIK_DATA_DIR`).

`python3 runtime/schema_manager.py verify` сверяет установленные архивы и XSD с реестром.
Во время анализа XML/GGE сеть не используется, `xsi:schemaLocation` не доверяется, и при
отсутствующей схеме результат получает явный статус `schema_not_installed` без имитации
семантической или стоимостной проверки.

ZIP извлекается стандартными средствами. Для единственного RAR нужны доступные в `PATH`
`unar` и поставляемый вместе с ним `lsar` для безопасной предварительной проверки;
если его нет, менеджер сообщает это ограничение и не объявляет полный набор установленным.
Подробная установка — в [INSTALL.md](../INSTALL.md); права третьих лиц — в [NOTICE.md](NOTICE.md).
